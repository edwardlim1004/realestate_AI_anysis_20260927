# ver1.0 통합 투자 대시보드

기본 URL: https://edwardlim1004.github.io/realestate_AI_anysis_20260927/

보존된 기존 화면: https://edwardlim1004.github.io/realestate_AI_anysis_20260927/ver0/

## 구성과 선택 동기화

- 상단과 지도 내 **서울 / 경기 / 대전** 버튼은 동일한 `area` 상태를 사용합니다.
- 지도 행정경계는 서울 25개 구, 경기 31개 시군, 대전 5개 구이며, 클릭하면 시군구 선택 · 지역 비교표 · 실거래 상세 · 아파트 평가 · 지역 위험 패널이 갱신됩니다.
- 지도 계열: 상대매력도, 가격 추세괴리, 거래유동성, 내재임대수익률, 미검증 지역 리스크. 지역별 신용·공급 자료가 없을 때는 **N/A**로 표시합니다.
- 경기 상대점수는 일부 시군의 경우 특정 권역(예: 분당/판교·영통/광교) 표본이므로 시군 전체 대표값이 아님을 점선 및 문구로 경고합니다.
- **대전은 행정경계와 5개 구 선택만 우선 활성화**했습니다. 현재 `data.js`에는 대전 지역별 확정 상대점수가 없으므로 가상 색상·수치를 생성하지 않습니다.

## 원본 파일과 역할

- `index.html`: ver1.0 메인 HTML
- `dashboard-v1/styles.css`: 디자인과 반응형 레이아웃
- `dashboard-v1/app.js`: 지역 연동 및 실제 데이터 기반 화면
- `dashboard-v1/region-boundaries.js`: 표기용 단순화 행정경계 (2023년 공개 원본 가공, 최신 행정경계와 다를 수 있음)
- `ver0/index.html`: 교체 전 기존 대시보드 **ver0.0 보존판**. `<base href="../">`로 기존 상대경로를 유지합니다.
- `data.js`: 국토교통부 지역 지표, 서울 25구·경기 31시군. `momentum/risk` 지역 점수는 **RESEARCH_ONLY**.
- `risk-data.js`: OECD·BIS 공식 전국 역사 백분위. 2007~09 글로벌 금융위기·2020 COVID-19 사건 구간 음영.
- `long-term-value/data/<시군구코드>.json`: 서울 개별단지 최근 5년 관측 중위가격·거래·전세 비교 (독립 산출물).
- `trade-details/index.json`, `trade-details/<지역코드>.json`: 공개검증된 **매매** 실거래 상세내역. 경기 일부는 부분권역 표본; 대전 및 전월세 공개 상세는 별도 구축 필요.

## 지표 해석 및 미구현 제한

1. 서울·경기 **지역 상대점수**는 가중치 35/15/15/20/15를 사용하는 실험 모형으로, 하락확률·매수추천이 아닙니다. 대전은 미산출.
2. **아파트별 5년 관측 중위가격**은 동일단지·유사면적의 거래 이력입니다. 구조적인 적정가격이나 5년 미래 예측과 구분합니다. 현재 별도 검증된 상세 평가 파일은 서울 25개 구 중심입니다.
3. **역사적 위험 백분위**와 위기 음영은 전국 동일 거시 시계열입니다. 지역을 전환해도 동일 전국 자료임을 표시하며, 이를 지역별 확률로 오용하지 않습니다.
4. **미래 하방확률(6개월·1년·3년)**은 HaR 표본외 검증 전까지 N/A. 승인된 실데이터 검증 없이 시안의 15/28/42% 예시를 표시하지 않습니다.
5. 현재월은 신고 중 잠정치입니다. 완결월 가격을 기준으로 상대점수를 계산하고, 현재월 잠정가격 선택 시 가격 정보만 참고용으로 변경합니다. 점수 산식은 변하지 않습니다.

## 데이터 경계와 저작자 표시

행정경계는 [KnellBalm/kr-admin-geojson](https://github.com/KnellBalm/kr-admin-geojson)의 공개 `sig.geojson`에서 서울·경기·대전만 추출하고 화면 표시를 위해 단순화했습니다. 공개 데이터의 기반 출처는 국가공간정보포털이며 원작자 저장소의 출처 표시 조건을 따릅니다. 원본 가공 데이터는 지도 참고용이며, 최신 법정 경계와 다른 경우 최신 공식 자료로 교체해야 합니다.
