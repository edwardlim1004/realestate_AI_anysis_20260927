🧮 종합점수 산출 공식 (판단 근거 전면 공개)

각 지역을 56개 지역 상대 백분위(0~100) 로 환산한 뒤, 아래 가중치로 합산합니다. 신호 기준: 종합점수 ≥62 매수고려 / 42~61 주의 / <42 관망.

종합점수 = 0.35×밸류에이션갭점수 + 0.15×모멘텀점수 + 0.15×거래유동성점수 + 0.20×리스크점수 + 0.15×전세가율점수

· 밸류에이션갭점수 = 현재가가 5년 구조적 추세선(로그회귀, 최근 12개월 제외) 대비 얼마나 낮은가의 56개 지역 내 백분위
· 모멘텀점수 = 최근 실거래 가격 변동률(트렌드 지표)의 백분위 — 단기 방향성
· 거래유동성점수 = 전월 대비 실거래 건수 증감률의 백분위 — 환금성
· 리스크점수 = 4대 리스크 지표(고점·환금성·금리·치안)를 역산한 백분위 — 낮을수록 유리
· 전세가율점수 = 전세/매매 비율의 백분위 — 높을수록 실수요 기반·갭투자 리스크 낮음
