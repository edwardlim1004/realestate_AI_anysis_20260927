# 광역시 자료 반영 검토 (2026-11-06)

- 부산 원본 1,626,819행, 7,040범위 저장·재읽기·층화 표본 대조 통과.
- 대구 원본 1,048,989행, 4,400범위 저장·재읽기 완료, 원출처 표본 대조 중.
- 광주는 대구 검증 후 순차 수집. 현황은 `metro_progress.json`을 기준으로 갱신한다.
- 과거 원자료 목표 202610, 가격 공통 마감은 전월 말 +30일 신고기한 경과 여부로 결정하며 원자료 목표를 넘지 않는다. 2026-11-06에는 202609. 12개월·전용80~90㎡의 매매·전세·월세를 분리한다.
- 원본 동일 행은 삭제하지 않는다. 부산 전체의 33,047개 반복 추가 행은 확정 중복 계약이 아니다. 가격 화면에는 원본 행 중위값과 동일 행을 한번만 센 민감도 중위값을 병기한다. 후자는 확정 거래수/가격이 아니다.
- 구·신 행정코드가 같은 구역·월·유형에 모두 자료를 반환하면 구역 가격 전체를 보류한다. 다른 월의 단일 유효 코드만 합칠 수 있다.
- 미검증 지역은 가격을 만들지 않는다. 원자료 fingerprint가 변하면 이전 공개 가격도 숨긴다. 원본 다운로드는 byte size와 SHA256을 모두 확인한다.
- 매매 해제 건 제외. 월세 보증금과 월 임대료는 별도 중위값이므로 동일 계약으로 해석할 수 없다. 지역 내 면적·단지 구성 효과가 남아 있다.
- 기존 서울·경기 점수와 신규 가격은 산식이 달라 직접 순위 비교하지 않는다. 기존 계산 및 대전 별도 4축 지표를 유지한다.
- 5년 가격 스냅샷은 R2·Drive 혼합 저장을 같은 인증/검증 경로로 읽는다. 오류 발생 시 기존 지역 스냅샷을 덮어쓰지 않는다.
- GitHub 쓰기는 원격 최신 내역 위에 rebase 후 최대 4회 push. 같은 파일의 충돌은 자동 덮어쓰지 않고 실패 처리한다.
- 증분 API는 기존 수집기와 동일 HTTPS 주소를 사용한다. 전월세전환율 표본 5건 미만의 기본값은 추정치로 표시한다.

오프라인 검증: 기존 수집기 41건 + 새 집계/저장소 회귀 6건, 5년 평가 5건. 실제 비공개 저장소 읽기 및 가격 배포는 GitHub Actions 결과를 별도로 확인한다.
