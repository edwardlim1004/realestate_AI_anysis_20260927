# R2 → F: 드라이브 안전한 단방향 자동 동기화

이번 변경은 사용자 Windows PC에 **자동 설치되거나 실행되지 않습니다**. GitHub PR을 병합해도 Windows 예약 작업은 생성되지 않습니다. 사용자가 별도의 파일을 실행한 경우에만 설정됩니다.

## 사전 조건

- Windows 10/11, Python 3.11 이상(\`py -3\` 실행 가능)
- 사용자 지정 \`F:\` 드라이브 연결 및 충분한 여유 공간
- GitHub 원본: \`edwardlim1004/realestate_AI_anysis_20260927\`
- Cloudflare R2 버킷 \`edward-seoul-apartment-data\` 및 Account ID
- **중요**: GitHub 쓰기용 기존 R2 키를 PC에 재사용하지 말고, Cloudflare R2에서 **새로운 Object Read Only 토큰**을 **이 버킷만** 대상으로 발급하세요.
- 로그인한 개인 Windows 계정의 **Windows 자격 증명 저장소**에 해당 읽기 전용 키를 보관합니다.
- 토큰 유출 시 Cloudflare 콘솔에서 해당 토큰만 폐기합니다. 기존 수집용 GitHub 비밀키에는 영향이 없습니다.

## 최초 설치

1. GitHub 저장소를 사용자 PC에 다운로드하거나 \`git clone\`하세요.
2. \`seoul-apartment-collector/windows\` 폴더의 \`1_초기설정.bat\` 실행
3. 보안 저장소 설치용 Python 패키지 \`keyring\` 및 R2 SDK \`boto3\`가 사용자 계정에 설치됩니다.
4. 새 읽기 전용 R2 Access Key ID와 Secret Access Key, Account ID를 명령창에 입력합니다. **채팅/GitHub 소스/메모장에는 기록하지 마세요.**
5. \`2_수동시험.bat\` 실행. 처음에는 최대 **25MB**만 받아 테스트합니다.
6. 원래 요청한 F: 폴더에 출력된 \`서울아파트_매매_R2_2026.csv\`와 \`서울아파트_전월세_R2_2026.csv\` 등을 확인합니다. 초기 데이터에는 일부 구·월만 있을 수 있습니다.
7. 확인 후 \`3_매일밤11시_예약설치.ps1\`을 PowerShell에서 실행합니다. 작업 스케줄러의 **오후 11시** 예약을 설치합니다. PC는 켜져 있고 해당 사용자가 로그인되어 있어야 합니다.
8. 해제는 \`4_예약해제.ps1\`을 실행합니다. 다운로드한 파일은 삭제하지 않습니다.

## PC 사용에 대한 보호장치

- 외부에서 PC로 접속할 서버·포트·원격제어 기능이 없습니다.
- 읽기 전용 토큰은 지정 버킷에 대해서만 사용: PC에서 R2 데이터를 삭제하거나 수정할 수 없습니다.
- 사용자 본인 Windows 계정으로만 실행, 관리자 권한 요청 없음. 예약작업도 최저 권한 사용.
- 다운로드 속도 기본 **2MiB/s 이하**로 제한; 한 번에 **256MiB 이하**의 변경분만 다운로드.
- 마지막 2GiB 디스크 여유 공간 보호. F 드라이브 미연결 시 파일 변경 없이 중단.
- 중복 실행 잠금, 다운로드 중 \`.part\`, CSV 생성 중 \`.pending\` 임시 파일을 사용하여 완료 후 교체.
- 기존 수동 작성 파일이나 일반 \`서울아파트_매매_2026.csv\` 같은 이름은 절대 덮어쓰지 않고, 별도 \`_R2_YYYY.csv\` 이름을 사용.
- 상태·로그: \`%LOCALAPPDATA%\EdwardSeoulAptSync\`; 인증키는 로그에 기록하지 않음.
- GZIP 데이터 검증 후 확정, GitHub/Cloudflare API 요청에는 속도 및 파일 크기 제한 적용.
- 월별 폴더와 원본 GZIP은 \`F:\...\1.서울아파트 매매전월세 거래 정보\_R2_작업데이터\원본압축\`에 저장됩니다.
- 인터넷·PC 전원 문제로 중단되면 다음 실행에서 남은 변경분만 재시도하며, 미완료 다운로드 파일은 그대로 확정하지 않습니다.
- 밤 11시 예약은 PC를 깨우도록 설정하지 않음. 배터리 사용 중 정지하는 정책을 사용합니다.
- 작업 스케줄러의 Windows 고급 정책이 회사 PC 보안설정에 따라 거부될 수 있습니다.

## 예약 실행 전/후

- 최초 설치 스크립트는 외부 Python 패키지를 다운로드하므로 공식 Python/패키지 배포처만 사용하고 설치 로그를 확인하세요.
- \`git pull\`을 예약 작업에서 자동 수행하지 않습니다. 프로젝트 파일 수정이 F: 데이터까지 확산되지 않습니다.
- 지정된 F: 폴더와 \`%LOCALAPPDATA%\EdwardSeoulAptSync\` 외에는 쓰기 작업을 하지 않습니다.
- 예약 해제 후 Cloudflare의 읽기 전용 토큰을 폐기하면 동기화 접근을 차단할 수 있습니다.
- CPU/스토리지 성능 저하가 우려되면 수동 시험으로만 사용하거나 예약 주기를 주 1회로 변경할 수 있습니다.
