# 수집 진행률과 저장공간을 함께 보내는 카카오 알림

기존 매일 09:00 한국시간 알림에 세 저장소의 사용량과 보호 상태를 합칩니다.
카카오 기본 텍스트 템플릿 한도 내에서 매매·전월세 진행률, 합계/목표, 전일 증가,
실제 확인일 일치 여부, 오류 수와 공간 정보를 함께 표시합니다. 실제 실행 대기열 때문에
도착 시각이 늦어질 수 있습니다. 새 형식은 v2 날짜별 영수증으로 하루 한 번만 전송합니다.
첫 적용일에는 기존 v1 알림을 이미 받았어도 갱신된 메시지를 한 번 추가 전송합니다.
전일 증가분은 v2가 없는 첫날에는 기존 v1 영수증과 비교합니다.

## 사용량의 범위

- Git 코드: GitHub repository API의 size(KiB)를 바이트로 변환합니다. **1GB는 관리 목표이며
  계정 무료 총량이 아닙니다.** Actions 실행파일은 만료되지 않은 아티팩트를 페이지 끝까지
  합산하고, 캐시는 별도 API로 조회합니다. 모두 이 저장소 범위이며 계정 전체 청구량이 아닙니다.
  실행파일/캐시의 계정 유료·무료 한도를 임의로 추정하지 않습니다.
- R2: ListBuckets와 모든 버킷의 ListObjectsV2 전체 페이지를 합산합니다. 실제 객체 크기와
  저장소 내부 제어 파일도 포함합니다. 전체 열거가 실패하면 알려진 버킷 사용량만 하한으로
  표시하고, 계정 전체 사용률과 남은 용량을 만들지 않습니다.
- Google: 기존 OAuth drive.file 권한으로 about.storageQuota를 조회합니다. 사용률과 잔여량은
  usage/limit를 사용하므로 Drive 외 서비스 및 Workspace 공유 할당량도 반영됩니다.
  Drive 전용량/휴지통은 별도 진단 항목입니다. 한도가 미제공이면 사용률을 추정하지 않습니다.
- 알림의 MB/GB/TB는 10진 단위입니다. R2의 10GB는 Standard 저장의 월간 무료 기준을
  이해하기 위한 비교값입니다. 실제 청구는 일별 최고 저장량을 기간 평균한 GB-month와
  요청 횟수에 따릅니다. 저장 용량 감시가 모든 R2 서비스의 비용 0원을 보증하지는 않습니다.

## R2 원본 저장 보호

이 프로젝트의 아파트 수집기와 GSADF 게시기는 같은 R2 예산 파일을 사용합니다.
전체 계정 조회가 성공하고, 기존 객체 크기 대비 증가량을 반영한 보수적 예상 사용량이
**8,000,000,000바이트 미만**일 때만 새 원본을 R2에 올립니다. 작은 제어 파일을 위한
1MB도 남겨 둡니다. 암호화된 토큰과 64KB 이하 GSADF 복구 포인터는 제어 데이터입니다.

If-Match/If-None-Match 조건부 쓰기로 동시 작업이 같은 잔여 공간을 중복 사용하지 못하게
예약합니다. 업로드 실패나 결과 불확실 시 예약을 취소하지 않고, 축소/삭제에 따른 여유도
자동 환급하지 않습니다. 이는 실제보다 이른 대체 저장을 선택할 수 있는 보수적 처리입니다.
카카오의 실제 사용량 수치는 예산 파일 대신 객체 전체를 다시 측정한 값입니다.

안전선 도달, 계정 합계 조회 실패 또는 예약 실패 시 R2 원본 저장을 중지하고 Google로
전환합니다. Google 용량을 확인하고 SHA256/MD5/크기 검증이 완료돼야 수집 완료로 기록합니다.
Google도 확인/저장에 실패하면 완료를 기록하지 않고 다음 실행에서 재개합니다.
GSADF는 검증된 Drive 묶음을 가리키는 작은 복구 포인터를 남기고 다음 실행에서 해당
Drive 묶음의 SHA256을 확인하여 복구합니다. 기존 R2 원본은 자동 삭제하지 않습니다.

이 예산은 이 프로젝트의 협조하는 원본 업로더를 통제합니다. 같은 계정에서 별도 도구나
사용자가 직접 수행하는 업로드까지 차단하는 Cloudflare 계정 과금 상한 기능은 아닙니다.

## 진단과 검증

daily_progress_report.json에 조회 시각, 측정 범위, 사용량 및 미확인 상태를 보존합니다.
접근 실패는 0GB나 정상 상태로 표시하지 않습니다. 영수증과 토큰은 기존 비공개 R2에
보관하며 자격증명은 로그나 Git에 기록하지 않습니다.

```bash
python seoul-apartment-collector/test_storage_budget.py
python seoul-apartment-collector/test_storage_routing.py
```

검증 범위: 버킷/페이지 합산, 제한된 권한, 동시 예약 경합, 불확실한 쓰기 결과,
Google 전체 계정 용량, GitHub 저장 유형 분리, 200자 내 표시, 대체 저장 실패 시 미완료 유지,
GSADF Drive 복구 시 해시 검증, 기존 수집/백업/카카오 중복 방지 회귀 테스트.
