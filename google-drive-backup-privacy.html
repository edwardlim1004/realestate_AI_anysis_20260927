Edward Seoul Apt Backup — 개인정보처리방침 / Privacy Policy

최종 수정 / Last updated: 2026-10-20

1. 앱의 목적 / Purpose

개인 소유자가 Cloudflare R2에서 관리하는 서울 아파트 공공 거래자료를 본인 Google Drive에 연도별 CSV 파일로 백업하기 위한 앱입니다. 다른 사용자에게 제공하는 상용 서비스가 아닙니다.

This personal-use app backs up the owner's Korean public apartment transaction archives from Cloudflare R2 to the same owner's Google Drive. It is not offered as a commercial multi-user service.

2. Google 데이터 접근 범위 / Google user data accessed

Google OAuth https://www.googleapis.com/auth/drive.file 권한을 요청합니다. 이 권한으로 앱이 만든 전용 폴더 및 파일을 조회·생성·수정하고, 체크섬·파일 크기·관리용 메타데이터를 확인합니다. 다른 Google Drive 개인 파일이나 Gmail·연락처·캘린더 데이터는 요청하거나 수집하지 않습니다.

We request only drive.file. We create, read metadata for, and update app-created backup folders/files, including checksums, file size, and synchronization metadata. We do not request access to unrelated personal Drive files or to Gmail, contacts, or calendars.

3. 데이터 사용 및 저장 / Use and storage

승인된 Google Drive 계정의 앱 전용 폴더에 백업 CSV를 보관합니다. 자동화는 GitHub Actions에서 실행하며 백업 원본은 소유자의 비공개 Cloudflare R2에 남아 있습니다. Google OAuth Refresh Token은 최초 GitHub Secrets에 주입되며 이후 비공개 R2에 암호화하여 저장하고, 액세스 토큰은 백업 실행 중 API 인증에 사용합니다. 워크플로 로그와 진단 결과에는 구간 수·행 수·파일 크기 등 운영 정보만 기록하도록 구현되어 있습니다.

Backup CSVs are stored in an app-created folder in the owner's Google Drive. Source archives remain in the owner's private Cloudflare R2 bucket. Automation runs on GitHub Actions. Refresh tokens are bootstrapped through GitHub Secrets and stored encrypted in private R2; access tokens authenticate API calls. Logs and backup reports contain operational statistics rather than OAuth secret values.

4. 제3자 제공 / Sharing and service providers

Google 사용자 데이터를 광고·분석·마케팅 목적으로 사용하거나 판매하지 않습니다. 승인 없이 Google Drive 파일을 다른 사용자에게 공유하지 않습니다. 백업 기능 수행을 위해 Google Drive, GitHub Actions, Cloudflare R2 서비스를 사용합니다.

We do not sell or use Google user data for advertising, marketing, or profiling, and the app does not share Drive backup files with other Google users. Google Drive, GitHub Actions, and Cloudflare R2 are technical service providers supporting the backup workflow.

5. 보존 및 삭제 / Retention and deletion

백업 파일은 소유자가 Google Drive에서 직접 삭제할 때까지 유지됩니다. GitHub에서 자동 백업을 중지해도 기존 파일은 자동으로 삭제되지 않습니다. Google 계정 보안 설정에서 앱 접근권한을 철회하면 추후 Drive API 접근을 막을 수 있습니다. 저장된 암호화 토큰과 원본 R2 파일은 자동 삭제되지 않으며, 소유자가 GitHub Secrets·Cloudflare R2에서 별도로 폐기할 수 있습니다. GitHub Actions 진단 아티팩트는 설정된 보존 기간에 따라 관리됩니다.

Files remain until the owner deletes them in Google Drive. Disabling backups does not erase existing files. The owner may revoke OAuth access in Google Account settings; encrypted stored tokens and source R2 files must be separately deleted by the owner if desired. GitHub Actions report retention follows repository workflow settings.

6. 보안 / Security

앱은 Google Drive의 전용 폴더에서만 파일을 생성·갱신하고 파일 공개 설정이나 공유 설정을 변경하지 않습니다. R2 원본 압축파일의 SHA-256을 검증하며 Drive에 저장한 백업은 MD5와 길이를 비교합니다. OAuth 인증정보를 공개 GitHub 소스에 넣지 않습니다.

The app does not set Drive file permissions or create share links. It validates R2 source SHA-256 hashes and uploaded Drive file checksums and sizes. OAuth tokens and client secrets are not committed to public source files.

7. 연락 / Contact

앱 소유자에게 연락이 필요한 경우 프로젝트 GitHub Issues를 통해 문의할 수 있습니다. Google OAuth 승인화면에도 사용자 지원 이메일이 표시됩니다.

For inquiries, use the project's GitHub Issues. The OAuth consent screen also lists the user-support email.
