# ECOS 유동성 독립 검증 보고서 — 2026-10-23

**결정: HOLD_SHADOW / 종합 6대 지표 편입 금지.** 이 보고서는 자동화한 기술·통계 검토이며, 독립된 인간 전문가의 최종 승인은 아닙니다.

## 재료와 출처

- `risk-data/liquidity/raw.csv`: 공식 ECOS 관측치 1,192개 (M2 275, Lf 275, L 275, CPI 276, 명목 GDP 91).
- `risk-data/liquidity/summary.json`: one-sided HP 지표의 과거 53개 분기 점수, 2013-Q2~2026-Q2.
- `risk-data/risk_raw.csv`: OECD `KOR / REAL_HPI / Q` 분기별 실질 주택가격지수.
- `risk-data/liquidity/score_vintages.csv`: 실제 저장된 **파생점수** 스냅샷 1개.
- `risk-data/liquidity/revision_history.csv`: ECOS 수정 이벤트 0건.
- 제공기관: https://ecos.bok.or.kr/api/ , OECD Analytical House Prices https://data-explorer.oecd.org/ .

## 모형 비교 절차 (사후 수정된 자료를 이용한 exploratory pseudo-OOS)

1. 목표변수: `100*ln(REAL_HPI[t+h]/REAL_HPI[t])`, h = 4 또는 8분기.
2. t시점 예측에 2분기 전 유동성 점수 사용. 모든 학습 목표변수는 결과 종료 시점 +1분기가 이미 지난 경우만 허용.
3. 최소 학습 표본 12개 뒤 각 분기에서 expanding OLS (설명변수는 단일 유동성 점수) 적합.
4. 같은 학습 관측치의 과거평균을 기준 예측으로 두고 RMSE, MSE skill = `1-MSE(OLS)/MSE(mean)` 비교.
5. 사후 모델 선택 및 과거 전체 표본 회귀계수를 현재 OOS 예측에 쓰지 않음. 다만 **원자료 자체는 최신 수정본**이므로 실제 발표 당일 데이터가 아닌 제약이 남음.

| 결과 | 4분기 | 8분기 |
|---|---:|---:|
| 평가 시점 | 2017-Q4~2025-Q2 | 2018-Q4~2024-Q2 |
| 표본외 개수 | 31 | 23 |
| 유동성 OLS RMSE (%p) | 5.599295 | 10.063026 |
| 과거평균 RMSE (%p) | 5.525526 | 9.770860 |
| MSE skill | -2.6879% | -6.0698% |
| 방향 | 기준모형보다 열위 | 기준모형보다 열위 |

**판단:** 지정한 단변량 예측모형은 미래 실질 주택가격의 4·8분기 변화 예측에 부가 성능을 입증하지 못함. 예측력 게이트 = FAIL. 이것은 모든 유동성 연구·다변량 선행위험지표가 무용하다는 뜻이 아님.

## 실제 빈티지 안정성

- 한 번의 공식 ECOS 데이터 회수시점에 대한 파생점수 기록은 1개. 본 보고서의 시험에서 자동화가 여러 차례 같은 현재 데이터를 회귀해도 빈티지 개수를 늘리지 않음.
- 최소 6개의 **서로 다른 실시간 관측일에 저장된 ECOS 원 관측치 스냅샷**과 각 시점에 알려진 내용, 최초공표/수정/소급개정 구분이 필요함.
- 가장 최근 수정본으로 2013~2026 관측치를 잘라 계산하는 방법은 one-sided HP의 시간방향 검사는 할 수 있지만 **공식 개정에 대한 안정성 검증**을 대신하지 못함.
- 해당 증거 확보 전 revisionStability = INSUFFICIENT_VINTAGES. 언제든 PASS로 자동 변경하는 우회는 금지.

## 기술 및 경제적 판단 검토

- **시간누설:** `noLookAhead` 자동 게이트는 과거 표본 절단에 대한 불변성만 검사하며, 당시 통계 발표일·정정본의 가용성을 보증하지 않음. 현재 pseudo-OOS는 2분기 시차를 채택해 보수적으로 완화했으나 완전 해결되지는 않음.
- **2008년 위기:** 원자료는 2003년부터이나 HP 초기기간/백분위 warm-up으로 계산된 점수는 2013-Q2부터 시작함. 이 모델로 2008년 실시간 사전경보 능력을 검증했다고 주장하지 않아야 함.
- **구조적 혼동:** Marshall K의 명목 M2/연율화 분기 명목 GDP, 계절조정 여부/분기 단위 정의/통계 개편 비교 재검토 필요. 실질 M2와 Lf/L 증가율이 신용축과 얼마나 중복되는지 정량 평가해야 함.
- **역할 구분:** 유동성의 역사적 상태 지표와 주택가격 하방위험 예측기는 용도가 다름. `23.36/100`은 가격하락확률이 아님.
- **통계적 검정력:** 4·8분기 수익률은 시점이 겹쳐 상관되며 n=31,23은 작음. 예측 오차비만으로 통계적 유의성을 주장할 수 없음.
- **데이터보안 및 비용:** ECOS/OECD raw는 누적 갱신하며 데이터의 원시 대용량 보관은 기존 R2를 우선 사용. 본 회귀 검정은 적은 관측치만 읽으며 별도 API 키 불필요.

## 후속 승격 기준

1. 공식 ECOS 최초공표 원본 빈티지 최소 6개 이상을 R2에 시점별 보관하고 checksum/관측치 수정 비교표 생성.
2. 발표일과 월별/분기별 공표시차를 반영한 실제 당시 정보 집합으로 재검정. 예측 목적·목표변수를 사전 고정, 침체/하방위험과 상태 측정을 구분.
3. 기준모형 대비 재현 가능한 OOS 우위, 주요 위기/비위기구간 오경보와 신용축 중복성 검토. 제3자 검토자, 일자, 검증 지문 명시.
4. `promotion.json`은 사람의 승인과 충분한 증거가 갖춰질 때까지 계속 `enabled:false`. 6대 종합 점수에는 추가하지 않음.
