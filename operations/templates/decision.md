# 사용자 결재안
- 작업 ID 및 한 줄 요약:
- 현재 상태: 연구 / 구현 / 검증 / 배포 준비 (서로 혼동 금지)
- 변경되는 동작과 영향을 받는 모듈·화면·데이터:
- 선택지: 승인 / 보류 / 수정 요청 / 반려
- 증거: 기준 commit, PR, 원천·설정·코드 hash, 날짜, 실행 로그:
- 주요 지표: PASS/FAIL/HOLD/NOT_RUN, 기준 대비 개선·악화:
- 독립 검증 결과 및 최악 시나리오, 반론:
- 비용/보안/저장량/API/품질 영향:
- 변경 허용 범위, 복구 절차 및 중단 트리거:
- 사용자 승인 여부: 비어 있음 (명시적 결재 전 결코 승인 처리하지 않음)
- 승인 시각/범위/commit SHA/자료 hash/결재 유효기간:
