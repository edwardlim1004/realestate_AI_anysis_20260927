# ChatGPT 대화 정리표

현재 대화 목록은 이 변경으로 이동/이름변경되지 않는다. 사용자가 다음 이름으로 정리할 때 기능 ID를 공통으로 사용한다.

| 기존 대화 | 권장 이름 | 기능 ID |
|---|---|---|
| 프로젝트 점검 확인 | 00 총괄·결재·진행현황 | 전체 |
| 부동산 데이터 저장 | 01 데이터 수집·품질 | data |
| 저장·카카오 관련 대화 | 02 저장·백업·알림 | storage |
| 유동성 검증 완료 | 03 유동성 연구·검증 | liquidity |
| GSADF 모듈 구축 and 검증 | 04 GSADF 버블검정 | gsadf |
| HaR 모듈 구축 검증 | 05 HaR 하방위험 | har |
| 장기 가격평가 모듈 연결 | 06 장기 가격·전세가치 | valuation |
| 화면·실거래 상세 관련 대화 | 07 위험 대시보드·거래상세 | dashboard |
| 대장옥션 공경매 옥션사이트 | 08 경공매 서비스 | auction |
| 그록봇 프로젝트 활용 여부 | 09 인프라·도구 검토 | storage 또는 별도 기획 |

채팅은 논의 공간, GitHub 작업패킷과 PR은 구현·검증의 기준 기록으로 사용한다. 완료처럼 보이는 채팅 제목으로 검증 상태를 판단하지 않는다.
