- 관측: 2026-10-31 Actions Build Apartment Five-Year Valuations
- 증거: https://github.com/edwardlim1004/realestate_AI_anysis_20260927/actions/runs/41208352776
- 현상: 서울 25개 구에 대해 sale/2026/.../202605.csv.gz 또는 202606.csv.gz 읽기/검증 중 ValueError, 작업 실패.
- 원인: 미확정. 현상만으로 R2 데이터 손상 또는 전체 원천 누락이라고 결론 내리지 않는다.

## 비파괴 확인 순서
1. 오류 객체 key, 원본 저장 백엔드(R2 or Drive), 콘텐츠 SHA256, gzip 정상성, CSV 스키마/헤더/지역코드를 기록 (개인 데이터 공개 금지).
2. 기존 수집기 및 5년 평가 빌더가 쓰는 컬럼명/파일 포맷/압축/스토리지 라우팅이 일치하는지 비교.
3. Drive fallback 파일과 R2 원본의 해시·길이 및 Manifest/서명 형식을 확인.
4. 하나의 시군구·월 데이터로 재현하는 오프라인 테스트와 누락/스키마 변형 테스트를 먼저 작성.
5. 안전한 수정 PR에서 성공한 구만 생성하고 불명확한 경우 이전 검증본 보존.
6. 25구 대상 Actions 재실행·재현/영향 검토는 사용자 승인받은 범위에서만 수행.

## 금지
원본 삭제·덮어쓰기, 임의 0 채움, 성공여부 조작, 정상 처리되지 않은 최신 가격을 신규 결과로 게시.
