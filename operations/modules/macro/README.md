# 09 거시경제·역사적 위험

기능 ID: macro

OECD/BIS 전국·글로벌 거시 역사 백분위. 서울·경기·대전 지역 단위 위험확률과 구분하고 Observation_Key 및 공표시점 추적

## 현재 연결 경로
- [risk-monitor](../../../risk-monitor)
- [risk-data](../../../risk-data)
- [risk-data.js](../../../risk-data.js)

## 작업 요청

python tools/ai_task.py macro "수행할 목표"

명령은 작업지시만 생성하고 어떤 작업도 자동 실행하지 않는다. [중앙 운영규정](../../README.md), [승인 게이트](../../RELEASE_GATES.md), [현재 상태](../../STATUS.md) 준수. 운영/연구 상태는 MODEL_REGISTRY.json 기준으로 확인하며 미검증을 정상가동으로 표기하지 않는다.
