# 외부 데이터 연동 경계

현재 앱은 src/data/mock.js의 가상 예시만 사용합니다.

실제 서비스 연동 시에는 허가된 데이터 소스(예: 공식적으로 제공되는 법원경매·온비드 데이터, 정식 계약을 통한 제공 API)에서 서버가 수집·정규화한 데이터를 JSON으로 전달하는 별도 어댑터를 만드세요.

주의:
- 대장옥션의 비공개 API, 로그인 세션, 결제 벽, 차단 장치를 우회하지 않습니다.
- API 키와 개인정보는 웹 페이지 및 저장소에 저장하지 않습니다.
- 원문 사건 식별자, 기준일, 출처, 갱신시간, 상태값, 오류를 반드시 보존합니다.
- 원본 데이터 부재 시 0이나 임의 낙찰가로 보간하지 않습니다.
- AI 권리분석은 문서 원문 수급, 출처 추적, 법률가 검토 없이 결과를 생성하지 않습니다.

권장 응답 스키마: docs/DATA_CONTRACT.md.
