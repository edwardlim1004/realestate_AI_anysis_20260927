# 기존 지도검색 UI 복원 — Classic v11

기존 개인 v11.4의 map.html / map.css / naver_sdk_adapter.js / live_data.js를 분석하여 화면 구조와 기능을 다시 구현했습니다. 대장옥션 원본 사이트와 공식 연동되지 않은 **독립 연구판**입니다.

## 사용법

1. 지도 검색 화면에서 이전 advanced 버전에 저장한 공개 Maps Client ID가 있으면 자동 네이버 지도 연결을 시도합니다. 없으면 '지도 설정/진단'에서 Client ID를 입력하고 브라우저 저장 후 실행하세요. Secret은 사용하지 않습니다.
2. 보유 DB 자료가 없다면 왼쪽 '기존 SQLite 직접 연결'에서 auction_v11.sqlite3를 선택하세요. 이전 2026-10-17 저장본은 물건 21건·좌표 0건으로, 원문 자료가 현재와 다를 수 있습니다.
3. 좌표 없는 물건은 오른쪽 '전국 물건 DB'의 Geocoding 메뉴로 주소당 API를 별도 동의 후 요청할 수 있습니다. 비용이 발생할 수 있으며 자동 결과는 주소가 정확히 일치할 때만 적용합니다.
4. 지도 축소 시 확인된 좌표가 있는 현재 DB 물건을 동 단위로 묶고, 확대 시 개별 최저가 마커로 보여줍니다. 지역 전체 사건 수가 아닙니다.
5. 위성·지적도, 거리·면적 측정, 진단 로그 저장, 수동 시험 마커, 관심목록, 사건 검색/상세 및 일정 기능을 제공합니다.

## 기능 범위

| 기능 | 지원 현황 |
|---|---|
| 이전 왼쪽 세로 메뉴 및 지도 검색 화면 | 구현 |
| 네이버 Dynamic Map·위성·지적도 | SDK 연결 구현; 실제 계정·타일은 사용자 브라우저에서 검증 |
| 거리 및 면적 | 지도상 좌표 기반 계산; 법적 필지 면적 아님 |
| SQLite 데이터 읽기 | 브라우저 로컬 파일/IndexedDB |
| 검색·관심·일정·상세·지역 수 클러스터 | 현재 반입 물건 기준 |
| Geocoding 및 지도 마커 | 사용자 동의 후 요청; 미확정 주소 자동 마커 없음 |
| SDK 진단 / 저장 Client ID 자동 연결 | 구현 |
| 요금 무료 잔여량 | 한도 안내 및 네이버 콘솔 수동 입력값 계산; 실시간 API 조회 아님 |
| AI 점검/입찰 계산/CSV·JSON/비교 | [advanced/](../advanced/) 기존 도구로 연결 |
| 전국 실시간 법원·온비드, 입찰 결과, 공식 AI 권리판단 | 미연결(공식 API·서버·검증자료 필요) |
| 아파트 실거래 CSV 자동 수집 | 로컬 v11.4 서버에 남아 있음; Pages 백엔드 없음 |

저작권: 원본 저장 사진·캡처·제3자 HTML은 GitHub 공개 페이지에 배포하지 않았습니다. 기존 사용자 자료는 브라우저에서만 불러오고 원문 검증 전에 실제 물건의 법적 상태나 정확한 필지 위치를 주장하지 않습니다.
