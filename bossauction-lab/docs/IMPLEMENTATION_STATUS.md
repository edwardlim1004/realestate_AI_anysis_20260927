# 구현·검증 상태 (2026-10-23)

| 기능 | 상태 |
| --- | --- |
| 검색·상세·일정·관심·비교·계산기 | 가상 또는 사용자 JSON 기반 |
| 지도검색 | 지역 도식·필터 구현, 실제 위치 지도 아님 |
| 데이터 연동 | 권한 있는 JSON 수동 입력, 공식 실시간 API 연동 아님 |
| 로그인 | 임시 게스트 작업공간, 회원 인증 아님 |
| 권리분석 | 사용자 체크리스트, AI·법률판정 아님 |
| 실시간 법원경매·온비드 데이터 | 미구현 (공식 API 권한과 서버 필요) |
| 정확한 위치 기반 지도 | 미구현 (주소·좌표 및 지도 API 필요) |
| 정식 회원 로그인 | 미구현 (인증 서버 및 개인정보 안전장치 필요) |
| 실제 AI 권리분석 | 미구현 (문서·AI 연동·법률 검토 체계 필요) |

구현 내용은 자동 테스트와 배포 기록을 따로 확인해야 한다. 실입찰 판단에 사용하지 않는다.
