# 대장옥션 공개 기능 관찰 기록

대상: https://www.bossauction.co.kr/
확인일: 2026-10-23

## 공개 검색에 의해 확인된 메뉴/범위
- 대장옥션 홈페이지: 법원 경매·공매 검색과 AI 권리분석 등 기능 소개.
- 로그인 전 메뉴: 종합검색, 경매 일정/결과, 법원별·소재지 검색, 공매 검색, 차량/중기 검색, 이해관계인 검색, 당사자 검색, 지도검색, AI채팅 등.
- 문서·교육: 경매서식 다운로드, 입찰표 작성 예시, 경매용어사전, 경매관련 도표.

## 접근 한계
웹 접근 시 공식 사이트에서 자동화 접속 차단 안내를 반환했다. 공개 검색 색인의 노출 정보 외 상세 DOM/JS/내부 API, 인증 및 유료 기능은 확인하지 못했다. 인증 회피·차단 우회·원본 에셋 복사는 수행하지 않았다.

## 기능별 구현 상태
| 범주 | 현재 상태 |
| --- | --- |
| 통합검색(유형·지역·물건·키워드·정렬) | 가상 데이터로 동작 |
| 경매·공매 물건 요약/상세 | 가상 데이터로 동작 |
| 일정/결과 | 가상 일정 목록만 동작, 낙찰 결과 미연동 |
| 관심물건 | 브라우저 localStorage로 동작 |
| 물건 비교 | 3건 한도 내 동작 |
| 입찰 비용 시뮬레이터 | 사용자 가정으로 계산 |
| 지도검색, 차량/중기, 당사자 검색 | 미구현 |
| 사용자 로그인, 결제, 유료 정보 | 미구현 |
| AI 권리분석, 배당 분석 | 미구현 (점검표만 표시) |
| 실시간 경공매 API | 미연동 |

본 프로젝트는 대장옥션 공식 코드의 복사본이 아닌 독립적인 클린룸 UI/기능 프로토타입이다.
