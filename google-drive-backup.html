Edward Seoul Apt Backup

Personal Google Drive backup utility / 개인용 구글 드라이브 자동 백업

이 도구는 사용자가 보관하는 서울 아파트 매매·전월세 공공 거래자료를 Cloudflare R2 저장소에서 읽어, 사용자가 승인한 Google Drive 계정으로 연도별 CSV 백업을 수행합니다.

This is a personal-use backup utility. With the owner's consent, it transfers public Korean apartment transaction archives from a private Cloudflare R2 bucket into annual CSV files in the owner's Google Drive.

작동 방식 / How it works

  1. GitHub Actions가 예약 실행하여 R2에 저장된 압축 원본의 파일 크기와 SHA-256 체크섬을 검증합니다.
  2. 매매·전월세를 각각 연도별 CSV 파일로 정리합니다. 완료되지 않은 수집 구간이 있는 연도는 부분 데이터일 수 있습니다.
  3. Google Drive API drive.file 권한으로 앱 전용 Edward_부동산데이터_R2백업 폴더에 생성·갱신합니다.
  4. 동일한 원본이 이미 백업돼 있으면 불필요한 재업로드를 생략합니다. R2 원본이나 기존 개인 Drive 파일을 삭제하지 않습니다.

Google 권한 / Google permissions

이 앱은 https://www.googleapis.com/auth/drive.file만 요청하며, 자신이 만들거나 사용자에게 명시적으로 선택된 Drive 파일을 관리할 수 있습니다. Google Drive 전체 접근 권한, Gmail, 연락처 및 캘린더 권한은 요청하지 않습니다.

The app only requests the Google Drive drive.file scope to create and maintain files it creates. It does not request general access to all Drive files, Gmail, contacts, or calendars.

소유자 제어 / Owner control

앱은 소유자 본인만 사용하는 비상업적 도구입니다. Google 계정의 보안 설정에서 접근 권한을 언제든 철회할 수 있으며, GitHub 저장소의 GDRIVE_BACKUP_ENABLED 변수를 false로 변경하면 예약 백업을 중지할 수 있습니다.

The owner can revoke authorization in their Google Account or disable scheduled backups in GitHub Actions at any time.
