# HaR / House Prices at Risk — 독립 연구 모듈

현재 상태: **RESEARCH_ONLY / 종합위험지표 미반영**.

## Method
IMF GFSR April 2019, Chapter 2의 하위 5% 분위수회귀 프레임워크를 참고한 한국 단일국가 시계열 모델입니다. IMF 공식 추정값이나 완전한 복제는 아닙니다.

- 종속변수: OECD 실질 주택가격지수의 향후 4분기 및 12분기 **누적** 변화율(%).
- 설명변수: 4분기 실질가격 모멘텀, (PIR+PTR)/2-100, BIS 신용/GDP 갭.
- 학습: 원점별 확장창, 관측 가능한 미래 결과가 이미 발표된 샘플만 학습. 최소 60개 분기.
- 검증: 표본외 예측 원점 최소 12개, 5% 미만 실현비율 검토, 비교모형/위기 구간 별도 검증.
- 순차적 관측시점의 4/12분기 결과는 중첩됩니다. 독립시행의 단순 신뢰구간은 사용하지 않습니다.

## 실행
```bash
pip install pandas numpy statsmodels
python har/build_har.py
```

입력: `risk-data/risk_raw.csv` (기존 OECD/BIS 수집 스크립트가 관리).
출력: `har/results.json` (연구 결과만 저장).

## 승인 전 필수 조치
1. 원천 시계열의 최신 공식 관측치를 GitHub Actions에서 정상 수집했는지 확인.
2. OECD/BIS 과거 데이터 개정에 의한 **실시간 정보 누출**을 피하기 위해 발표일/빈티지 자료를 구축하고 시점별 학습데이터 재생성.
3. 2008–09, 2020, 2022–23 등 위기/긴축 구간에서 표본외 5% 분위수의 캘리브레이션과 pinball loss를 무조건부 과거 분위수 기준모형과 비교.
4. 점추정치 불확실성, 구조변화, 지역별(서울·경기/전국) 분리 가능 여부 검토.
5. 별도 승인 커밋 이후에만 6대 위험지표 합성 점수 포함. **현재 어떠한 합성점수도 변경하지 않음**.

자료 출처: https://www.imf.org/en/Publications/GFSR/Issues/2019/03/27/Global-Financial-Stability-Report-April-2019

가계 DSR은 원천자료로 이미 확보되어 있지만 기본모델은 과적합 위험을 줄이기 위해 3개의 설명변수만 사용합니다. 추가 피처는 표본외 성능 검증 후 승인하세요.
