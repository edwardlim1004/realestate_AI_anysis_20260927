# 아파트 5년 장기 가격평가 — 독립 모듈

공개 사이트: https://edwardlim1004.github.io/realestate_AI_anysis_20260927/long-term-value/

기존 대시보드 상단 링크, 또는 실거래 건수 → 거래 선택 → 이 아파트의 5년 장기 가격평가 보기로 이동합니다.

## 기능과 데이터 보안

- index.html: 웹 UI
- model.js: 강건 로그추세 / 조건부 5년 가격계산
- build_snapshots.py: R2 인증 원본 → 공개 가능한 단지별 요약 JSON
- data/자치구코드.json: GitHub Actions에서 자동생성
- test_build_snapshots.py: 자료 누락 및 산식 검증

비공개 R2에 GitHub Pages 브라우저가 직접 접근하지 않습니다. GitHub Actions만 GitHub Repository Secrets의 R2 연결정보를 사용합니다. 원본 거래행과 비밀키를 공개파일에 게시하지 않고, 단지별 월/연 가격 중위값과 거래 수만 게시합니다. 추가 국토교통부 API 요청은 사용하지 않습니다.

## 산출 규칙

1. 거래신고 기한(계약일부터 30일)을 고려해, 해당 월의 마지막 날짜 + 30일이 지난 완결 후보 월부터 과거 60개월을 사용합니다. 예를 들어 2026-10-21 기준 컷오프는 2026-08입니다. 늦은 정정/해제는 이후에도 반영될 수 있습니다. 원천은 서울 25개 구 아파트 매매 및 전월세 압축 CSV이고 SHA256 무결성을 확인합니다.
2. 취소 신고 제거. 법정동 + 단지명 + 지번 + 전용면적 5㎡ 구간이 같은 거래를 묶습니다. 층/향/내부상태는 미보정입니다.
3. 최근 12개월 매매 중위가격은 최소 5건 필요. 첫 12개월 중위값은 최소 3건 필요. 전세는 월세금 0원인 순수 전세 보증금만 비교하며 최근 12개월 최소 3건 필요.
4. 과거 연평균 변화율 = (최근 12개월 매매 중위값 / 첫 12개월 매매 중위값)^(1/4)-1. 두 12개월 관측기간의 중간시점이 4년 간격이기 때문입니다.
5. 추세 기준선은 5년간 매매 월별 중위가격의 Theil–Sen 로그회귀. 12개월 이상 서로 다른 관측월 + 최초/말월 간격 36개월 이상을 요구합니다. 괴리율 = 최근 12개월 매매 중위값 / 최근 12개월 중앙시점 회귀추세값 -1.
6. 5년 후 가격 시나리오 = 최근 12개월 매매 중위값 × (1+연간 가정변화율)^5. 기본 -2%, +2%, +5%는 예시일 뿐, 예측/검증된 전망이 아닙니다.
7. 양호/보통/제한적/보류 등급은 거래표본 품질이고 투자 점수가 아닙니다. 구 전체의 과거 60개월 데이터와 개별 아파트를 혼용하지 않습니다.

**주의:** 추세선 자체는 구조적 적정가격이 아닙니다. 추세 상단을 '고평가', 하단을 '저평가'로 확정하지 않습니다. 성장률 가정에는 세금, 인플레이션, 거래비용 및 자금조달비용이 포함되지 않습니다.

## 최초 수동 실행 및 자동 갱신

1. GitHub Actions → Build Apartment Five-Year Valuations → Run workflow → main.
2. 기존 수집기에서 이용하는 R2_ACCOUNT_ID, R2_ACCESS_KEY_ID, R2_SECRET_ACCESS_KEY, R2_BUCKET_NAME을 Repository Secrets에서 재사용합니다. 코드에 키를 절대 직접 쓰지 않습니다.
3. 검증 및 생성 작업의 성공을 확인합니다. 생성된 data/11710.json은 송파구 자료입니다.
4. 사이트에서 자치구와 단지를 선택하거나 기존 실거래 상세보기 링크로 이동합니다.
5. 이후 매일 한국시간 오전 08:10 무렵 자동 갱신(실제 시각은 GitHub Actions 스케줄 지연 가능). 입력 원본 SHA256 집계의 자치구별 지문이 같으면 재다운로드/재커밋하지 않습니다.

**자료 부족 처리:** 자치구별 매매·전세 원본이 각각 60개월 중 48개월보다 적으면 결과를 생성하지 않습니다. 원본 접근/검증 오류 시 이전 자료를 덮어쓰지 않습니다. 원본 일부가 R2에서 Google Drive 전용 보관으로 이동된 경우 현재 빌더에서는 읽을 수 없어 오류를 표시하며 임의보간하지 않습니다.
