평가 방법과 해석 범위

동일 아파트의 최근 거래가격, 과거 5년 분포와 거래량, 전세 중위가격을 개별 확인합니다. 장기 상승률만으로 ‘저평가’ 또는 ‘고평가’를 단정하지 않습니다. 미래 시나리오는 직접 입력한 성장률에 따른 조건부 계산이며 확정 적정가격이 아닙니다.

원천: 국토교통부 공식 아파트 매매·전월세 실거래가 API. 원본: 비공개 Cloudflare R2. 공개 자료: 월별·연도별 집계만. 최근 완결월까지 60개월을 사용하며 가장 최신 신고월(잠정치)은 기본 평가에서 제외합니다. 아파트명과 지번, 약 5㎡ 면적구간이 같은 거래를 비교하고, 취소 거래는 제외합니다. 상세 재현·수집상태는 GitHub 모듈 설명을 참조하세요.
